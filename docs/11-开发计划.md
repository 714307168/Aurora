# 11 · 开发计划与完成记录

> 原路线图已在 Aurora `1.4.0` 收口。本文保留实现边界与验收证据，后续维护不得把“构建通过”当成功能通过。

## 批次一 · 阅读体验 ✅

- 代码块：语言识别、复制、行号、18 行折叠；行数按去掉最后一个换行后的 `split().length` 计算。
- 阅读进度：仅 `post.php` 输出 `#read-progress`，固定在 62px 顶栏下沿。
- 主题切换：`data-theme` + localStorage + 系统偏好，按钮同步 `aria-pressed`。
- 图片：正文图片 lazy/async，点击灯箱，ESC/遮罩关闭并清理事件监听。
- TOC：文章页右栏 h1/h2/h3，章节不足 2 个不显示。

## 批次二 · 内容增值 ✅

- `#post-reading-meta`：JS 统计中文字符与英文词，按 400 字词/分钟估算。
- `$this->related(4)`：使用 Typecho 1.3 原生标签关联组件，不写自定义拼接 SQL。
- `Aurora::post_views()`：要求部署前确认 `views` 字段；前台绝不执行 DDL；使用 `expression('views','views + 1',false)` 原子累加，Cookie 保存最近 200 篇做基础去重。
- 首页/归档显示浏览量，侧栏热门榜改为 `views DESC, created DESC`，无字段时回退评论数。
- `.post-breadcrumb`：首页、分类、当前标题。

## 批次三 · SEO / 流量 ✅

- `header.php`：canonical、RSS alternate、OG、Twitter Card，去掉重复 keywords。
- `Aurora::og_image()`：HTML img → Markdown 图片 → 绝对图片；相对地址补全站点 URL。
- `Aurora::json_ld()`：输出 `BlogPosting` + `BreadcrumbList`，用 `json_encode` 防 XSS。
- `scripts/generate-sitemap.php`：查询公开文章/页面/分类/标签，临时文件 + rename 原子替换。
- RSS 入口位于 head、顶部导航和页脚；本站全文订阅配置已开启。
- 线上运维：`/etc/cron.d/aurora-sitemap` 每天 03:23 重建；根目录 `robots.txt` 声明 `Sitemap: https://www.liuyg.cn/sitemap.xml`。

## 批次四 · 互动 / i18n ✅

- 评论 Provider：`off/native/giscus/artalk`。默认 `off`，符合本站关闭评论策略。
- Giscus/Artalk 只有参数齐全时才加载外部资源，属性和 JS 参数均转义/JSON 编码。
- 喜欢/收藏：按文章 CID 存 localStorage，只表示当前浏览器状态，不显示虚假累计数。
- 打赏：后台二维码 URL 为空时完全不输出。
- `Aurora::t()`：中文/英文 UI 字典，后台 `aurora_lang` 切换。

## 测试与发版链路 ✅

1. `tests/test_theme_features.py`：8 项功能/安全/发版契约，必须先红后绿。
2. PHP 全模板 `php -l`、JS `node --check`、Shell `bash -n`。
3. `qa-scan.py` 同步后检查真实线上：canonical、JSON-LD、阅读信息、互动按钮、浏览量、TOC、代码增强、备案、空链接、JS 错误；任一异常退出 1。
4. 发布前自动备份线上主题，QA 失败自动回滚。
5. 生成 sitemap 后核验 XML 和 HTTP 200。

- 线上 HTML 引用的新 `?v=` 已递增；
- Git 工作区干净且远端 `main` 与本地一致；
- 文档与代码同步，无“路线图已写、功能未落地”的纸上工程。
