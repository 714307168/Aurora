# 11 · 开发计划（执行细则）

> 基于 [路线图](10-下一期路线图.md) 的**可执行开发计划**。每项含：需求、实现思路、涉及文件、验收标准。

> 通用约定：改 CSS/JS 必须同步 bump `?v=`；改完跑 `python3 scripts/qa-scan.py`；改代码必更对应文档。

## 批次一 · 阅读体验（本期主攻，做完先发版）

### 1.1 代码块行号 + 长代码折叠
- **需求**：代码块显示行号；超过 18 行自动折叠，可展开；复制按钮不带行号。
- **实现**：`aurora.js` 的 `enhanceCode()` 增强——为每个 `.post-body pre` 包裹 `.code-wrap`，加 `.line-nums`（1..N），为 code 加 `.code-scroll`；行数 >18 加 `.collapsed` + 折叠按钮。
- **涉及文件**：`assets/aurora.js`、`assets/aurora.css`（`.code-wrap/.line-nums/.code-fold`）。
- **验收**：行号与代码逐行对齐；长代码默认折叠、点击展开；复制内容不含行号；控制台无报错。

### 1.2 阅读进度条
- **需求**：文章页顶部细进度条，随滚动显示阅读进度。
- **实现**：`post.php` 加 `<div id="read-progress">`；`aurora.js` 监听 scroll，按 `(scrollY)/(docH-winH)` 更新宽度；`aurora.css` fixed 顶部 2px 渐变条。
- **涉及文件**：`post.php`、`assets/aurora.js`、`assets/aurora.css`。
- **验收**：滚动时进度条平滑跟随；首页/列表页不出现；移动端正常。

### 1.3 亮/暗主题切换
- **需求**：深色为主，加浅色模式；点击顶部按钮切换；localStorage 记录；可跟随系统。
- **实现**：`header.php` 顶部加 `<button id="theme-toggle">`；`aurora.js` 切 `html` 的 `data-theme="light"`，写 `localStorage`；`aurora.css` 用 `:root[data-theme="light"]` 覆盖一套浅色变量；首次读取本地/系统偏好。
- **涉及文件**：`header.php`、`assets/aurora.js`、`assets/aurora.css`。
- **验收**：切换即时生效、刷新保持、默认深色；代码块/侧栏/卡片在浅色下可读。

### 1.4 图片懒加载 + 灯箱
- **需求**：正文图片 `loading=lazy`；点击图片弹层放大，可关闭。
- **实现**：`aurora.js` 给 `.post-body img` 加 `loading=lazy`，点击注入 `.lightbox` 遮罩显示大图；`aurora.css` 做遮罩/动画。
- **涉及文件**：`assets/aurora.js`、`assets/aurora.css`。
- **验收**：图片懒加载不闪烁；点击放大、ESC/点击关闭；友链/侧栏图片不受影响。

## 批次二 · 内容增值

### 2.1 文章字数 + 阅读时长
- 正文 `textContent` 统计字数，中文按字、公式按 400 字/分钟估算；`post.php` 元信息加"约 N 字 · M 分钟"。
- 文件：`post.php`、`aurora.js`、`aurora.css`。

### 2.2 相关文章推荐
- 按当前文章标签取同类文章（`Widget_Related` 或自定义 SQL 按 `typecho_relationships`），正文尾部展示 3-5 篇。
- 文件：`post.php`、`aurora.css`。

### 2.3 文章浏览量统计
- 数据库 `contents` 加 `views` 字段；访问 `post` 时 `+1`（可用 `Typecho_Db` 更新）；热门榜改按 views 排序。
- 文件：`functions.php`、`post.php`、`sidebar.php`。

### 2.4 面包屑导航
- `post.php` 正文顶部：首页 › 分类 › 标题（schema 用 BreadcrumbList）。
- 文件：`post.php`、`aurora.css`。

## 批次三 · SEO / 流量

### 3.1 结构化数据 JSON-LD
- `header.php` 按页面类型输出 `Article` / `BreadcrumbList` / `Person` JSON-LD。
- 文件：`header.php`。

### 3.2 og 首图 + canonical
- 完善 `og:image`（取首图/默认封面）、`twitter:card`；`post` 输出 `<link rel="canonical">`。
- 文件：`header.php`。

### 3.3 订阅加强
- `header.php` 醒目订阅入口（RSS/Atom），bot 支持全文输出。
