# 04 · 前端功能（assets/aurora.js）

单文件 IIFE，原生 JS，无依赖。结构：

```js
(function () {
  "use strict";
  // 1. 移动菜单开合
  // 2. 回到顶部
  // 3. 代码块增强（语言识别 + 一键复制）-> enhanceCode()
  // 4. 文章目录 TOC -> buildToc()
  // 5. init() = enhanceCode(); buildToc();
  // readyState 处理：loading 则等 DOMContentLoaded，否则立即 init
})();
```

## 1. 移动菜单开合

- 触发：`#nav-toggle` 点击 → `#aurora-nav` 加/去 `.open`
- `.open` 时 CSS 将导航从 `display:none` 变为 flex 纵向（仅 ≤768px 生效）

## 2. 回到顶部

- `#to-top` 点击 → `window.scrollTo({top:0, behavior:"smooth"})`

## 3. 代码块增强（enhanceCode）

**逻辑**：遍历 `.post-body pre`，为每个 `pre>code` 注入一个 `.code-head`（语言标签 `.code-lang` + 复制按钮 `.code-copy`），并加**行号列 `.line-nums`** 与**长代码折叠**。

- **行号**：按 code 行数生成 `.line-nums span`（1..N），pre 改为 flex 布局，行号列固定左、code 内横向滚动。
- **折叠**：行数 > 18 时 pre 加 `.code-collapsed`（最大高度 460px + 渐变遮罩），`.code-head` 出现 `.code-fold`（"展开 N 行"）按钮，点击展开并移除按钮。
- 复制按钮复制的是 `code.textContent`，**不含行号**。

**语言识别**（优先级）：
1. 若 `code.className` 含 `language-xxx`，直接用（来自 Markdown 围栏 / Typecho）
2. 否则用启发式 `detectLang()`：扫描代码前 900 字符，命中关键词越多越优先 → 返回语言 key

**语言映射表** `LANG_NAMES`：把 key 显示成人类可读（如 `cpp→C++`、`bash→Shell`、`py→Python`）。

**关键词表** `HINTS`：14 种语言的识别特征，如 batch（`@echo off`/`setlocal`）、java（`public static void main`/`System.out.print`）、go（`package main`/`import "fmt"`）…

**复制**：`navigator.clipboard.writeText(code.textContent)`；失败降级 `fallback()`（临时 textarea + `execCommand`）。复制后按钮文字变「已复制」，1.6s 后还原。

**注意**：此函数假定代码已由 highlight.js 着色（footer 里 `hljs.highlightAll()` 先行执行）。

## 3.5 阅读进度条（readProgress）

仅文章页（`post.php` 有 `#read-progress` 容器）时启用。监听 scroll，按 `scrollY / (docHeight - winHeight)` 计算进度，更新顶部 3px 渐变条宽度（`bar.style.width`）。

## 3.6 亮/暗主题切换（themeToggle）

`header.php` 顶部有 `#theme-toggle` 按钮（🌙/☀️）。点击在 `html` 的 `data-theme="dark|light"` 间切换，写入 `localStorage['aurora-theme']`；初始从本地读取，无则跟随系统 `prefers-color-scheme`（默认深色）。`aurora.css` 用 `:root[data-theme="light"]` 覆盖一套浅色变量。

## 3.7 图片懒加载 + 灯箱（enhanceImages）

给 `.post-body img` 加 `loading="lazy"` 和 `decoding="async"`；点击图片弹出 `.aurora-lightbox` 遮罩放大，点击遮罩或 `ESC` 关闭。

## 4. 文章目录 TOC（buildToc）

- 扫描 `.post-body` 内 `h1/h2/h3`（≥2 个才生成，否则不显示目录）
- 为每个标题设 `id="toc-sec-N"`，生成 `<ol.toc-list>`（h3 → `.toc-h3` 缩进，其余 → `.toc-h2`）
- 点击目录项 → `scrollTo({top: 目标.offsetTop - 76, behavior:"smooth"})`（留出吸顶导航高度）
- **scrollspy**：滚动时按当前 `scrollY+90` 判断所在章节，给对应目录项加 `.active`（高亮）
- 所有目录项注入 `#post-toc` 容器（位于右侧栏 `.side-toc`，仅文章页）

## 5. 初始化时机

```js
if (document.readyState === "loading") {
  document.addEventListener("DOMContentLoaded", init);
} else { init(); }
```
`aurora.js` 在 footer 末尾加载，`readyState` 通常已是 complete，直接 `init()`。

## 关键约束

- 所有 CSS 类（`.code-head`/`.code-lang`/`.code-copy`/`.toc-list`/`.active`）的样式在 `aurora.css` 中定义，改样式去 CSS，改逻辑来此 JS。
- **改了 aurora.js 后，必须递增 `footer.php` 里 `aurora.js?v=YYYYMMDD` 的版本号**，否则缓存不生效。
