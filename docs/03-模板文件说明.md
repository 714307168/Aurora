# 03 · 模板文件说明

## `header.php`

负责 `<head>` 与顶部栏：

- title / description / keywords（单份，不重复）；文章页 keywords 读取 `typecho_fields.keywords`，首页/分类/标签/搜索页读取 Typecho 站点 `keywords` 选项，禁止拿 description 冒充关键词；
- canonical、RSS alternate、OG、Twitter Card；
- 文章页 `BlogPosting + BreadcrumbList` JSON-LD；
- 首图支持 HTML、Markdown、相对 URL，无图回退 `assets/logo.svg`；
- 导航：首页、独立页面、分类、RSS、亮暗切换、移动菜单、搜索。

CSS URL 的 `?v=` 在这里，改 `assets/aurora.css` 后必须递增。

## `footer.php`

页脚版权、备案、RSS、回到顶部、highlight.js 浏览器版、`aurora.js?v=`。`aurora_copy=0` 只隐藏版权，不隐藏备案。

## `index.php` / `archive.php`

两栏文章列表：标题、摘要、日期、分类、真实浏览量。归档页覆盖分类、标签、搜索、作者；空结果有中英文提示。

## `post.php`

文章页 DOM 顺序：

1. `#read-progress`；
2. `.post-breadcrumb`；
3. 标题元信息（日期/分类/浏览量/字数与时长）；
4. `.post-body`；
5. 标签；
6. `.post-reactions`（喜欢/收藏）；
7. 可选 `.post-reward`；
8. `$this->related(4)` 相关文章；
9. 上下篇、作者、评论 Provider；
10. 右侧 TOC / 热门 / 标签。

`Aurora::post_views($this)` 在模板头部只调用一次，避免同一请求重复计数。

## `comments.php`

按 `aurora_comment_provider` 分流：

- `off`：显示评论关闭；
- `native`：仅 `allow('comment')` 时渲染 Typecho 评论列表/表单；
- `giscus`：参数齐全后加载 `giscus.app/client.js`；
- `artalk`：Server/Site 齐全后加载 Artalk。

本站默认 `off`，不会加载第三方脚本。

## `sidebar.php`

文章页：TOC、热门文章、标签云。其他页：搜索、分类、热门、标签、12 月归档。

热门榜优先 `views DESC, created DESC`；旧库无 views 时回退 `commentsNum`。URL 统一由 `Aurora::post_url()` 生成。标签字号/颜色随热度变化。

## `functions.php`

`Aurora` 提供：

- `e()` / `absolute_url()`：上下文安全输出；
- `lang()` / `t()`：zh-CN / en-US UI；
- `og_image()` / `canonical()` / `json_ld()`：SEO；
- `post_views()` / `post_url()`：浏览量与链接；
- `themeConfig()`：Typecho 识别的主题设置入口，注册主题、备案、赞助、评论 Provider 参数。

## 其他模板

- `page.php`：独立页面；评论仍按 Provider 策略。
- `page-links.php`：友链页，依赖 Links Plus。
- `404.php`：中英文 404 文案和首页入口。
- `style.css`：Typecho 主题声明与版本，目前 `1.4.0`。
