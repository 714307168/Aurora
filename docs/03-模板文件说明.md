# 03 · 模板文件说明

每个 PHP 模板的职责、关键 DOM 与可修改点。Typecho 模板通过 `$this` 访问当前页面数据（`$this->title()`、`$this->content()` 等）。

## `header.php` —— ` <head>` + 顶部导航

- 输出：`<title>`、favicon（`assets/logo.svg`）、`aurora.css?v=`、highlight.js 样式、meta/og 标签
- 结构：`.aurora-topbar` > `.topbar-inner`（brand + nav + search）
- 关键：
  - `.aurora-brand`（logo svg + 站名，链接到 `siteUrl`，点击回首页）
  - `.aurora-nav`：首页 + 页面列表 + 分类下拉（`.nav-drop > .drop-menu`）
  - `.nav-toggle`：移动端菜单按钮
  - `.topbar-search`：搜索框（`method=post`，`name=s`）
- 改 logo：编辑内联 SVG 或换 `assets/logo.svg`
- 改导航：`Widget_Metas_Category_List`（分类下拉）、`Widget_Contents_Page_List`（独立页面）

## `footer.php` —— 页脚 + 脚本

- 输出：`.aurora-footer`（品牌行 / 版权行 / 备案行）、`.to-top`、highlight.js、`aurora.js?v=`
- 版权行：`Theme <a href="https://github.com/714307168/Aurora">Aurora</a>`
- 备案行：读 `$this->options->aurora_beian`，空则不显示
- ⚠️ 改 `aurora.js`/样式后，这里要同步 `?v=` 版本号？—— 版本号在 `header.php`（css）和这里（js），**改 css/js 必须递增**

## `index.php` —— 首页（两栏）

```html
<div class="aurora-container layout">
  <div class="content-pane">          <!-- 主内容 -->
    <section class="home-hero">…</section>
    <section class="article-list">
      <article class="art-card">
        <h2 class="art-title"><a>标题</a></h2>
        <p class="art-excerpt">摘要(90字)</p>
        <div class="art-meta">日期 / 分类 / 评论数</div>
      </article>
    </section>
    <nav class="page-navigator">…</nav>   <!-- 分页 -->
  </div>
  <aside class="aurora-sidebar">need sidebar.php</aside>
</div>
```

## `archive.php` —— 归档/分类/搜索/标签/作者

复用 `index.php` 结构，`home-hero` 显示 `$this->archiveTitle(...)`。空结果渲染「😶 没有找到相关文章」。

## `post.php` —— 文章详情（两栏）

```html
<article class="aurora-post">
  <header class="post-head">
    <h1 class="post-title">标题</h1>
    <div class="post-meta">日期 / 分类 / 评论</div>
  </header>
  <nav class="post-toc" id="post-toc"></nav>   <!-- JS 填充目录 -->
  <div class="post-body">正文 <?php $this->content(); ?></div>
  <div class="post-tags">…</div>
  <nav class="post-nav">上一篇 / 下一篇</nav>
  <section class="post-author">作者</section>    <!-- 需后台设置 authorTitle -->
  need comments.php
</article>
```

- **进度条**：文章页正文上方 `<div id="read-progress">`，由 `aurora.js` 的 `readProgress()` 随滚动更新宽度（仅文章页）。
- **TOC**：`#post-toc` 空容器，由 `aurora.js` 的 `buildToc()` 依据 `.post-body` 里的 `h1/h2/h3` 生成。
- **作者块**：`$this->options->authorTitle` 为空则不显示（可选）。

## `page.php` —— 独立页面（单栏）

`.aurora-container`（无 `layout`，单栏居中）。标题 + 正文 + 评论。适合「关于」「归档说明」等页面。

## `page-links.php` —— 友链页（slug=links）

- 自动匹配：Typecho 对 slug=`links` 的独立页面使用 `page-links.php`
- 输出：`.aurora-links` 网格，调 `Links_Plugin::output('SHOW_IMG',0,null,32)`（需安装 Links Plus 插件）
- 深色卡片样式内联于该文件 `<style>` 块

## `comments.php` —— 评论

- 被 `post.php`/`page.php` 引入
- `allow('comment')` 为真：显示评论列表 + 表单；否则显示「🔕 评论已关闭」
- 全站当前已关闭评论（后端 allowComment=0）

## `sidebar.php` —— 右侧栏

模块（`.side-box`）按顺序：
1. 搜索 `.side-search`
2. 分类 `.side-cats`（`Widget_Metas_Category_List`，含文章数 `{count}`）
3. 热门文章 `.side-hot`（自定义 SQL 按 `commentsNum` 降序取 6 篇）
4. 标签云 `.side-tags`（`Widget_Metas_Tag_Cloud`，字号按 `count` 缩放 12-18px）
5. 归档 `.side-archive`（`Widget_Contents_Post_Date` 按月取 8 条）

**加模块**：复制一个 `.side-box` 结构，`widget(...)` 用 Typecho 内置 Widget。

## `404.php` —— 404 页

`.err-page`：大号渐变 404 → 文案 → 返回首页按钮。

## `functions.php` —— 辅助 + 设置

- `class Aurora`：
  - `og_image($widget)`：提取正文首图（og:image）
  - `is_post($widget)`：是否文章页
  - `sidebar_search($value)`：转义搜索值
- `aurora_theme_config($form)`：主题设置（详见 05），注册 `aurora_sidebar` / `aurora_copy` / `aurora_beian`
