# 05 · 主题配置

主题设置由 Typecho 标准入口 `functions.php::themeConfig()` 注册，入口：Typecho 后台 → 控制台 → 外观 → 设置外观。

## 设置项

| 键名 | 默认 | 作用 |
| --- | --- | --- |
| `aurora_sidebar` | `1` | 首页/归档/文章页右侧栏开关；关闭后单列居中 |
| `aurora_copy` | `1` | 页脚版权信息开关；备案行独立 |
| `aurora_lang` | `zh-CN` | 主题 UI：`zh-CN` / `en-US` |
| `aurora_beian` | 空 | 备案 HTML；管理员可信输入 |
| `aurora_reward_image` | 空 | 赞助二维码 URL；空则不显示 |
| `aurora_comment_provider` | `off` | `off/native/giscus/artalk` |
| `aurora_giscus_repo` | 空 | `owner/repo` |
| `aurora_giscus_repo_id` | 空 | Giscus Repo ID |
| `aurora_giscus_category` | `Announcements` | Giscus Category |
| `aurora_giscus_category_id` | 空 | Giscus Category ID |
| `aurora_artalk_server` | 空 | Artalk Server URL |
| `aurora_artalk_site` | 空 | Artalk 站点名 |

## 本站当前策略

- 评论保持关闭：`aurora_comment_provider=off`，同时正文 `allowComment=0`。
- RSS 全文：Typecho `feedFullText=1`。
- 备案号必须保留：豫 ICP 备案与公安备案由 `aurora_beian` 保存；主题仓库不硬编码站点专属值。
- 赞助位默认隐藏，只有管理员明确配置二维码才展示。

## 第三方评论启用条件

### Giscus

必须同时填写 Repo、Repo ID、Category ID；缺任一项时主题回退到“评论已关闭”，不会加载外部脚本。

### Artalk

必须填写 Server URL 与 Site；参数通过 `json_encode` 注入，禁止手写拼接 JS。启用前先确认 Artalk 服务端的数据合规与可用性。

## 数据库存储

Typecho 会把主题设置序列化到 `typecho_options`，不要手工向数据库写明文密钥。本主题评论配置不需要 Token/Secret；若未来增加凭据型配置，应放服务器受限环境文件，不放主题仓库。

## 新增设置项规则

1. 在 `themeConfig()` 注册控件并给安全默认值；
2. 模板读取时对空值兜底；
3. URL/HTML 属性必须 `Aurora::e()`，JS 值必须 `json_encode()`；
4. 同步更新本文、功能契约测试和 README。
