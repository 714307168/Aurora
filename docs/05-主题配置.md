# 05 · 主题配置

主题设置走 Typecho 的「外观设置」，由 `functions.php` 的 `aurora_theme_config($form)` 注册；存储为数据库 `typecho_options` 表的 `aurora_*` 项。

## 注册的设置项

| 键名 | 控件 | 默认 | 作用 |
| --- | --- | --- | --- |
| `aurora_sidebar` | Radio 开启/关闭 | 1 | 是否显示右侧栏；关闭后内容区单列居中 |
| `aurora_copy` | Radio 显示/隐藏 | 1 | 页脚版权信息（备案号始终保留） |
| `aurora_beian` | Text | 空 | 页脚备案号 HTML；留空不显示 |

后台位置：Typecho 后台 → 控制台 → 外观 → 设置外观 里的 Aurora 设置。

## 数据库存储

每个设置项实际是 `typecho_options` 里一行：

```sql
SELECT name, value FROM typecho_options WHERE name LIKE 'aurora_%';
-- 例:
-- aurora_sidebar | 1
-- aurora_copy    | 1
-- aurora_beian   | <a href="https://beian.miit.gov.cn/" ...>豫ICP备...号</a>
```

主题内读取：`$this->options->aurora_beian`（Footer 备案行）、`$this->options->aurora_sidebar`（未用/可在模板判断）。

## 备案号配置（重要）

主题**不硬编码**任何备案，完全通过 `aurora_beian` 展示。要填自己的备案，把「含链接的 HTML」放进该设置：

```html
<a href="https://beian.miit.gov.cn/" target="_blank" rel="noopener noreferrer nofollow">京ICP备00000000号</a>
```

- 留空 = 页脚不显示备案行
- 开源项目保持干净；部署到具体站点时由该站点后台/数据库填入即可

## 新增一个设置项的步骤

1. `functions.php` 的 `aurora_theme_config()` 里 `addInput()` 新控件
2. 模板里用 `$this->options->你的键名` 读取
3. 无注册项时读取返回空/默认，需在模板 `if(...)` 兜底

## 备注

- 切换主题时 `aurora_*` 选项可能残留在库里，不影响其它主题
- `aurora_beian` 是 HTML 片段，仅管理员可设置（视为可信输入）
