# 08 · 测试指南

## 1. 本地功能契约（必须先跑）

```bash
cd /root/aurora-theme
python3 -m unittest tests/test_theme_features.py -v
```

覆盖：内容增值、SEO/RSS、可选评论、本地互动、i18n、代码行数回归、无明显后门原语、发版 fail-closed、sitemap 纳入发布。

## 2. 语法检查

```bash
for f in *.php scripts/*.php; do /www/server/php/80/bin/php -l "$f"; done
node --check assets/aurora.js
bash -n scripts/release.sh
git diff --check
```

JS 必须用 `node --check`，禁止用 Python AST 检查 JavaScript。

## 3. sitemap 验证

```bash
AURORA_WEBROOT=/home/wwwroot/www.liuyg.cn /www/server/php/80/bin/php scripts/generate-sitemap.php
python3 -c "import xml.etree.ElementTree as E;print(len(E.parse('/home/wwwroot/www.liuyg.cn/sitemap.xml').getroot()))"
curl -sI https://www.liuyg.cn/sitemap.xml
```

通过标准：生成成功、XML 可解析、URL 数大于文章总数、HTTP 200。

线上实例还需确认：`systemctl is-active crond` 为 `active`，`/etc/cron.d/aurora-sitemap` 权限 0644，公网 `/robots.txt` 含 sitemap 声明。

## 4. 真实浏览器 QA

```bash
AURORA_SITE=https://www.liuyg.cn python3 scripts/qa-scan.py
```

脚本用 Chrome CDP 检查首页、TOC 文章、代码文章、友链、404。硬性检查：

- Aurora DOM、备案、canonical、无空 href/双斜杠；
- 文章页 JSON-LD、阅读信息、浏览量、两个互动按钮；
- TOC、代码块增强、highlight.js；
- `error` / `unhandledrejection`；
- 任一异常累计到 `failures`，最终 `sys.exit(1)`，不能只打印警告。

## 5. 发版验收

日常只执行：

```bash
bash scripts/release.sh "变更说明"
```

脚本先测本地，再备份/同步，最后测新线上版本；若线上 QA 失败自动恢复备份。最终首页、文章、友链、sitemap 必须全部 200。

## 常见失败

| 现象 | 根因 | 处理 |
| --- | --- | --- |
| 文章 500 | Theme API/Typecho 调用错误 | `php -l` + 错误日志，修后重跑 |
| 新 CSS/JS 不生效 | CDN URL 版本未递增 | 发版脚本自动 `max(当前+1, 今日)` |
| `require is not defined` | 引了 Node 版 highlight.js | 只能用 cdnjs 浏览器版 |
| JSON-LD 解析失败 | 手写 JSON/未转义 | 统一 `json_encode` |
| sitemap 404 | 根目录文件未生成 | 重跑生成器并检查权限 0644 |
| 浏览量不变 | 当前浏览器已有去重 Cookie | 换无痕浏览器验证，不要删生产数据 |
