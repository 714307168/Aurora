# 08 · 测试指南（回归 / 提效）

> 每次改动主题后，用本指南快速回归。命令均可直接复制执行，结果一目了然。

## 1. 快速自检（3 条命令）

```bash
# ① 可达性：全站 URL HTTP 状态（终端跑）
curl -s --noproxy '*' "https://www.liuyg.cn/" | grep -oE 'href="[^"]+"' | grep -oE 'index.php/archives/[0-9]+/' | sort -u \
  | xargs -I{} curl -s --noproxy '*' -o /dev/null -w "{} %{http_code}\n" "https://www.liuyg.cn/{}"

# ② 双斜杠 / 空 href 扫描（应为 0）
curl -s --noproxy '*' "https://www.liuyg.cn/" | grep -c '//index.php'          # 期望 0
curl -s --noproxy '*' "https://www.liuyg.cn/" | grep -c 'href=""'              # 期望 0

# ③ 关键 DOM（首页 200 + Aurora 主题 + 侧栏 5 模块）
curl -s --noproxy '*' "https://www.liuyg.cn/" | grep -oE 'assets/aurora.css|class="side-box"' | sort | uniq -c
```

期望输出：`双斜杠 0`、`空href 0`、`aurora.css` 与 `side-box` 命中 ≥ 5。

## 2. 深度回归（CDP 真实浏览器）

需先启动本地 CDP Chrome：见下方脚本 `scripts/qa-scan.py`，它会自动拉起 Chrome 并逐页检查。检查项：

| 页面 | 必检项 |
| --- | --- |
| 首页 `/` | 200、theme=Aurora、侧栏 5 模块、导航下拉、备案显示 |
| 文章页 `/archives/37/` | TOC（.post-toc a ≥ 2）、`.post-body` 渲染、侧栏 |
| 代码文章 `/archives/5/` | `.code-head` ≥ 1、语言标签、hljs 着色 |
| 友链 `/index.php/links.html` | `.aurora-links` 卡片、List 插件渲染 |
| 404 | `.err-page` 出现、返回首页按钮 |

## 3. 重点检查清单（改动后必看）

- [ ] **可达性**：首页 / 文章页 / 归档 / 分类 / 友链 / 404 全部 HTTP 200
- [ ] **链接健康**：全站无 `//` 双斜杠、无 `href=""` 空链接（siteUrl 用法）
- [ ] **TOC**：有 h1-h3 的正文出现章节目录，滚动高亮正常
- [ ] **代码块**：语言标签正确、一键复制可用、hljs 着色生效
- [ ] **侧栏**：搜索 / 分类 / 热门 / 标签云 / 归档 5 模块渲染
- [ ] **导航**：分类下拉可展开、logo 点击回首页、移动端菜单
- [ ] **页脚**：版权、备案号（`aurora_beian`）、Theme 链接指向 GitHub
- [ ] **版本号**：改过 css/js 后 `?v=` 已递增（否则 CDN 缓存旧文件）
- [ ] **console**：无 JS 报错（尤其 highlight.js / aurora.js）
- [ ] **响应式**：>768px 两栏侧栏在右，≤768px 单栏折叠

## 4. 常见失败信号

| 现象 | 可能原因 | 处理 |
| --- | --- | --- |
| 文章页 500 | 模板调用了未定义的 `Aurora::xxx()` | 函数名核对 functions.php |
| 改 css/js 不生效 | 版本号没递增 / CDN 缓存 | bump `?v=` |
| 控制台 `require is not defined` | highlight.js 用了 Node 版 | 换 cdnjs `highlight.min.js` |
| 链接空 / 双斜杠 | `siteUrl()` 用方法/漏 echo | 用 `<?php echo $this->options->siteUrl; ?>` |
| TOC 不出现 | 正文 h1-h3 < 2 | 正常；增加标题或检查 post-toc 容器 |

## 5. 复用脚本

仓库 `scripts/qa-scan.py` 封装了可达性 + DOM + console 检查，可直接跑：

```bash
python3 scripts/qa-scan.py
```

它会依次检查首页、文章页（TOC）、代码页（代码块）、友链、404，输出每页状态与关键 DOM 命中数。改动完跑一遍即可。
