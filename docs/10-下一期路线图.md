# 10 · 下一期功能路线图（Roadmap）

> 面向 Aurora 主题的下一阶段规划。按「价值 / 需求 / 工作量」排优先级，建议**先做 P0**。
> 每项标注：价值、工作量、依赖。落地时按批次推进，改完跑 `bash scripts/release.sh`。

## P0 · 阅读体验（技术博客刚需，优先做）

| 功能 | 价值 | 工作量 | 说明 |
| --- | --- | --- | --- |
| 代码块行号 + 语言图标 | 高 | 中 | `aurora.js` 加行号列 + 语言小图标，与现有复制/标签共存 |
| 长代码折叠 | 高 | 低 | 超过 N 行默认折叠，点击展开（技术长文常见） |
| 阅读进度条 | 高 | 低 | 顶部细进度条，跟随滚动 |
| 侧栏目录跟随 | 高 | 中 | 文章页侧栏放 TOC，滚动高亮当前（现在 TOC 在正文顶部） |
| 图片懒加载 + 灯箱 | 高 | 中 | `loading=lazy` + 点击放大查看（配图多的文章） |
| 亮/暗主题切换 | 高 | 中 | 深色为主，加浅色模式；记录 localStorage，跟随系统可选 |

## P1 · 内容增值

| 功能 | 价值 | 工作量 | 说明 |
| --- | --- | --- | --- |
| 文章阅读时长 + 字数 | 高 | 低 | 正文自动统计字数/预计阅读时长，元信息展示 |
| 相关文章推荐 | 中 | 中 | 按标签/分类取相关文章，放正文尾部 |
| 文章浏览量统计 | 中 | 中 | 自定义计数（Typecho 无内置），热门榜接真实点击 |
| 面包屑导航 | 中 | 低 | 分类 → 文章路径，利于定位与 SEO |
| 归档/标签云增强 | 低 | 中 | 标签云按热度配色、归档树 |

## P2 · SEO / 流量

| 功能 | 价值 | 工作量 | 说明 |
| --- | --- | --- | --- |
| 结构化数据 JSON-LD | 高 | 中 | Article / BreadcrumbList / Person，提升搜索点击 |
| OG / 首图优化 | 中 | 低 | 完善 og:image、twitter card，分享好看 |
| canonical + sitemap | 中 | 低 | 避免重复收录，利于收录 |
| RSS 订阅强化 | 中 | 低 | 全文输出 + 订阅按钮醒目 |

## P3 · 互动 / 运维

| 功能 | 价值 | 工作量 | 说明 |
| --- | --- | --- | --- |
| 第三方评论支持 | 中 | 中 | Giscus / Artalk / Waline，替代关闭的原生评论 |
| 文章点赞/收藏 | 中 | 中 | localStorage 免登录，文章页加互动 |
| 打赏/赞助位 | 低 | 低 | 技术博主可选 |
| i18n 国际化 | 低 | 高 | 面向开源/出海，工作量偏大，作远期 |

## 建议路线

- **第一批（下期核心）**：代码块行号/折叠 + 阅读进度条 + 亮暗切换 + 图片灯箱 —— 直接提升技术文阅读体验，工作量可控。
- **第二批**：阅读时长 + 相关推荐 + 文章浏览统计 + 面包屑 —— 内容增值。
- **第三批**：JSON-LD + canonical + og 完善 —— 流量收益。
- **远期**：评论 / 点赞 / i18n。

> 每个批次完成即发版（`bash scripts/release.sh 'feat: xxx'`），避免一次性攒太多。
