# 10 · 功能路线图（Roadmap）

> Aurora `1.4.0` 已完成原规划中的 P0–P3。后续只接受有明确需求和验收标准的新功能，避免“为功能而功能”。

## P0 · 阅读体验 ✅

| 功能 | 状态 | 落地 |
| --- | --- | --- |
| 代码块行号 + 语言识别 | ✅ | 行号、语言标签、复制，修复无末尾换行少算一行 |
| 长代码折叠 | ✅ | 超过 18 行默认折叠 |
| 阅读进度条 | ✅ | 顶栏下沿实时进度 |
| 侧栏目录跟随 | ✅ | h1–h3 TOC + scrollspy |
| 图片懒加载 + 灯箱 | ✅ | 正文图片 lazy/async + ESC 关闭 |
| 亮/暗主题切换 | ✅ | localStorage + 系统偏好 + ARIA 状态 |

## P1 · 内容增值 ✅

| 功能 | 状态 | 落地 |
| --- | --- | --- |
| 字数 + 阅读时长 | ✅ | 中文按字、英文按词，400 字词/分钟 |
| 相关文章推荐 | ✅ | Typecho 1.3 原生 `$this->related(4)`，按标签关联 |
| 浏览量统计 | ✅ | `contents.views`，Cookie 去重；热门榜按真实浏览量 |
| 面包屑 | ✅ | 首页 › 分类 › 标题，带可访问性标注 |
| 标签/归档增强 | ✅ | 标签按热度字号/颜色，归档扩至 12 个月 |

## P2 · SEO / 流量 ✅

| 功能 | 状态 | 落地 |
| --- | --- | --- |
| JSON-LD | ✅ | `BlogPosting` + `BreadcrumbList` + `Person` |
| OG / Twitter Card | ✅ | 首图支持 HTML/Markdown/相对路径，无图回退 logo |
| canonical | ✅ | 文章/页面 permalink，列表页按实际路径 |
| sitemap | ✅ | `scripts/generate-sitemap.php` 原子生成根目录 `sitemap.xml` |
| RSS | ✅ | head/nav/footer 订阅入口；站点 `feedFullText=1` 已确认 |

## P3 · 互动 / 国际化 ✅（默认安全关闭）

| 功能 | 状态 | 说明 |
| --- | --- | --- |
| 第三方评论 | ✅ | Off / Typecho / Giscus / Artalk；本站默认 Off |
| 喜欢/收藏 | ✅ | localStorage 免登录，仅本机状态，不伪造全站数字 |
| 打赏位 | ✅ | 后台填二维码 URL 才展示 |
| i18n | ✅ | `zh-CN` / `en-US` 主题 UI 字典，后台切换 |

## 版本里程碑

- `1.1.0`：阅读体验
- `1.2.0`：内容增值
- `1.3.0`：SEO / RSS / sitemap
- `1.4.0`：可选互动 + i18n + 发版链路加固

> 发版必须走 `bash scripts/release.sh "描述"`：功能契约 → 语法 → bump → 备份同步 → sitemap → 线上 QA → commit/push → HTTP 验证。
