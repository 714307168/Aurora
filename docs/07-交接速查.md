# 07 · 交接速查（30 秒上手）

> 给接手维护的 AI / 开发者：读完这张就能干活。细节看对应文档。

## 一句话
Aurora = Typecho 深色科技风博客主题（玻璃拟态 + 霓虹青蓝渐变 + 两栏 + 侧栏 + TOC + 代码增强）。

## 核心文件
| 文件 | 干什么 |
| --- | --- |
| `assets/aurora.css` | 全站样式 + `:root` 设计变量（配色/圆角/断点都在这） |
| `assets/aurora.js` | 前端逻辑：菜单/回顶/代码块语言识别+复制/TOC |
| `functions.php` | `class Aurora` 辅助 + Typecho 标准 `themeConfig` 主题设置 |
| `index.php`/`post.php` | 首页 / 文章页（两栏结构） |
| `sidebar.php` | 文章页 3 模块 / 其他页 5 模块，热门按真实浏览量 |
| `footer.php`/`header.php` | 页脚 / 头部（含 `?v=` 版本号引用） |

## 高频操作
- **换主色** → 改 `aurora.css` 的 `--aurora`/`--aurora2`，再 bump 版本号
- **加侧栏模块** → `sidebar.php` 复制 `.side-box` + Typecho Widget
- **改导航** → `header.php` 的 `.aurora-nav` 两个 Widget
- **发版** → 改完同步文档 → `bash scripts/release.sh "说明"`（自动测试、备份、上线 QA、commit/push）

## 必背坑（避免返工）
1. **改了 css/js 必须递增 `?v=` 版本号**（header 的 css、footer 的 js），否则 CDN 缓存不生效
2. **highlight.js 用 cdnjs `highlight.min.js`**，别用 npm `lib/common.min.js`（会 `require is not defined`）
3. **备案号**走 `aurora_beian` 设置，主题从不硬编码
4. **分页**容器 class 是 `.page-navigator`（不是 page-nav）
5. **发版顺序**是先本地契约，再同步，最后测新线上；QA 失败自动回滚
6. **评论默认关闭**，启用第三方 Provider 前必须填写完整参数
7. **TOC** 只在 `.post-body` 里 ≥2 个 h1/h2/h3 时显示
8. **友链页**需装 Links Plus 插件；卡片用 `--card-bg` 深色
9. `Aurora` 类的方法必须定义，模板调用别引未定义方法（会 500）
10. **改了代码必须同步更新 `docs/`**（见 06 §6），否则文档失效、交接失准
11. **`$this->options->siteUrl` 是属性不是方法**：必须 `<?php echo $this->options->siteUrl; ?>`（带 echo），用 `siteUrl()` 或漏 echo 会输出空字符串，导致链接 href 空/双斜杠

## 线上站 vs 仓库
- 仓库 `github.com/714307168/Aurora` = 通用开源主题，干净
- 线上 `usr/themes/Aurora` = 该主题在 www.liuyg.cn 的实例，备案号走数据库 option
- 改主题以仓库为准，改完同步线上；线上特有问题（备案）不动代码
