# 02 · 设计规范（设计系统）

所有视觉定义集中在 `assets/aurora.css`。改动以「只动 `:root` 变量」为优先，避免散落魔法值。

## 1. 配色变量（`:root`）

```css
:root{
    /* 主色：霓虹青 → 电蓝 渐变 */
    --aurora:#22d3ee;        /* 主青 */
    --aurora2:#3b82f6;       /* 辅蓝 */
    --aurora-grad:linear-gradient(135deg,#22d3ee,#3b82f6);  /* 主渐变，用于 logo/按钮/高亮 */

    /* 背景（深色三层 + 网格光晕叠加） */
    --bg-0:#070b14;
    --bg-1:#0b101c;
    --bg-2:#0f1626;

    /* 玻璃卡片 */
    --card-bg:rgba(255,255,255,.035);
    --card-bg-hover:rgba(255,255,255,.06);
    --card-border:rgba(255,255,255,.09);
    --card-border-strong:rgba(255,255,255,.16);

    /* 文字三级 */
    --text:#e7edf5;   /* 主 */
    --text-2:#a5b0c2; /* 次要 */
    --text-3:#6e7a8e; /* 弱 */

    /* 代码块 */
    --code-bg:#0d1117;

    --radius:12px;         /* 卡片圆角 */
    --shadow:0 8px 30px rgba(0,0,0,.35);
    --glow:0 0 22px rgba(34,211,238,.16);   /* 悬浮发光 */

    --font:"PingFang SC","Microsoft YaHei",-apple-system,sans-serif;
    --mono:"JetBrains Mono","Fira Code",Consolas,monospace;
}
```

**改配色**：改 `--aurora`/`--aurora2` 即为全局换主色；改 `--bg-*` 换背景；改 `--card-*` 调卡片密度。一处改动全站生效。

## 4. 响应式断点（全部在文件尾部）

```css
@media (max-width:768px){
    .aurora-container.layout{grid-template-columns:1fr;}   /* 两栏→单栏，侧栏折叠到正文下方 */
    .aurora-sidebar{position:static; flex-direction:row; flex-wrap:wrap}
    .side-box{flex:1 1 100%}
    /* 另一处 max-width:768px：缩小导航/字号/顶部 */
}
```

两栏布局在 `>768px` 生效；`≤768px` 折叠为单栏，侧栏模块横向堆叠到下方。

## 5. 动效约定

- 卡片 hover：`translateY(-3px)` + 阴影/发光 + 顶部渐变条淡入（`opacity 0→1`）
- 链接 hover：变色 + `text-shadow` 发光
- 返回顶部 / TOC 跳转：`behavior:"smooth"`
- 移动菜单、下拉：`transition` 过渡

## 6. 无障碍要点

- 交互按钮都有 `aria-label`（如 `去顶部`、`复制代码`、`返回首页`）
- `lang="zh-CN"`（header html）
- 主色对比度满足浅色文字在深底上的可读性
