# 01 · 概述与架构

## 1. 项目定位

Aurora（极光）是一款**完全原创的深色科技风 Typecho 博客主题**。核心卖点：

- 深色科技感（玻璃拟态卡片 + 霓虹青蓝渐变 + 网格光晕背景）
- 两栏布局：主内容 + 右侧栏（搜索 / 分类 / 热门文章 / 标签云 / 归档）
- 文章章节目录（TOC，滚动高亮）
- 代码块语言识别 + 一键复制 + 语法高亮
- 高阅读体验排版、响应式、页脚备案可配置

**开源协议**：MIT ｜ **线上演示**：https://www.liuyg.cn ｜ **仓库**：https://github.com/714307168/Aurora

## 2. 技术栈

| 层 | 技术 |
| --- | --- |
| 博客引擎 | Typecho 1.x（PHP） |
| 模板 | 原生 Typecho 模板（`index.php` 等），无框架 |
| 样式 | 纯 CSS（无预处理器），CSS 变量驱动的设计系统 |
| 前端脚本 | 原生 JS（单 IIFE，无构建、无依赖打包） |
| 语法高亮 | highlight.js（CDN，cdnjs） |
| 图标 | 主题内联 SVG + Unicode 符号（无图标库） |

零构建步骤、零第三方依赖打包——改完直接生效，无需 `npm`/`build`。

## 3. 目录结构

```
aurora-theme/
├── style.css         # Typecho 主题声明（@package/@author/@version/@link）
├── index.php         # 首页（两栏布局，文章列表 + 侧栏）
├── archive.php       # 归档 / 分类 / 搜索 / 标签 / 作者 列表页
├── post.php          # 文章详情页（标题/正文/TOC/标签/上下篇/作者/评论）
├── page.php          # 独立页面（单栏）
├── page-links.php    # 友链页（slug=links 自动匹配，用 Links Plus 插件）
├── comments.php      # 评论（列表 + 表单；被 post/page 引入）
├── sidebar.php       # 右侧栏（被 index/archive/post 引入）
├── header.php        # <head> + 顶部导航栏（logo/导航/搜索）
├── footer.php        # <footer> + 回到顶部 + 脚本引入
├── functions.php     # Aurora 辅助类 + 主题设置 themeConfig
├── 404.php           # 404 页
└── assets/
    ├── aurora.css    # 全站样式（设计系统 :root 变量 + 所有组件）
    ├── aurora.js     # 前端交互（导航/回到顶部/代码增强/TOC）
    └── logo.svg      # logo 及 favicon
```

## 4. 运行机制（请求如何渲染）

1. Typecho 按当前 URL 路由到某模板（首页→`index.php`、文章→`post.php`、页面→`page.php`/`page-links.php`）
2. 模板 `need('header.php')` 输出 `<head>` + 顶部栏，`need('footer.php')` 输出页脚 + 脚本
3. 列表/文章页用 `<div class="aurora-container layout">` 做两栏，右侧 `need('sidebar.php')`
4. `header.php` 引 `aurora.css`（带 `?v=` 版本号）、footer 引 `aurora.js`（带 `?v=`）

## 5. 关键约定

- **CSS 版本号**：`aurora.css/aurora.js` 引用都带 `?v=YYYYMMDD`，**每次改这两个文件必须递增版本号**，否则 CDN/浏览器缓存旧文件。
- **主题命名空间**：CSS class 统一 `aurora-*` / `post-*` / `side-*` 前缀；PHP 类名 `Aurora`（functions.php）。
- **备案号**：主题不硬编码备案，通过后台「页脚备案号」设置（`aurora_beian`）输出。
- **评论区**：全站评论已关闭，`comments.php` 会输出「评论已关闭」。
